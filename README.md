# 🎙️ NerdCode — Tecnologia, Magia e os Segredos dos Pixels

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da DIO.

O objetivo foi criar um podcast utilizando ferramentas de Inteligência Artificial para auxiliar na criação do roteiro, conteúdo e produção do episódio.

O podcast criado se chama **NerdCode — Tecnologia, Magia e os Segredos dos Pixels**.

O conteúdo é voltado para iniciantes que desejam aprender mais sobre o universo do **Frontend** de uma forma simples, divertida e descontraída.

---

## 🎧 Sobre o Podcast

O **NerdCode** é um podcast sobre tecnologia com foco no desenvolvimento Frontend.

Neste episódio, são apresentados:

* Uma curiosidade sobre CSS;
* Uma ferramenta utilizada por desenvolvedores Frontend;
* Conteúdo simples e acessível para iniciantes em programação.

---

## 🤖 Tecnologias e Ferramentas Utilizadas

* ChatGPT — Criação do roteiro;
* Ferramenta de geração de voz — Criação do áudio;
* Editor de áudio — Edição do episódio;
* GitHub — Hospedagem e versionamento do projeto.
